# 奶系定稿素材

目前随技能附有八位奶系成员的原图。做新成员时，沿用用户为那个成员确认的参考。下面的素材可直接随技能移动。

| 定稿素材 | 取用方式 |
| --- | --- |
| [奶蛙游戏原图](../assets/naiwa-pixel-v2.png) | 16 个姿势，按[切框数据](../assets/frame-regions.json)里的左、上、宽、高裁取。游戏图集不是严格等分，平均裁切容易混入邻帧。 |
| [五位奶伴游戏原图](../assets/followers-family-v2.png) | 从上到下为奶鼠、奶狗、奶蛋、奶龟、奶兔，每行 4 个姿势。切框文件给出了横、纵分界。 |
| [奶猫定稿](../assets/milk-cat.png) · [奶鸡定稿](../assets/milk-hen.png) | 两条图均为 4 格，每格 64 × 64。它们来自已确认的像素角色，最初以奶家族谱为参考。 |
| [原图和聊天效果对照](../assets/model-comparison.png) | 每组左边是原图，右边是成品中的一帧。比较比例、光影和缩小后的辨识度。 |

游戏原图来自项目的 `naiwa-binding/dist/assets/`，切框来自同版 `atlas-regions.js`。两种结尾的 GIF 只示范播放节奏。每枚表情的演法由新的聊天意图决定。
