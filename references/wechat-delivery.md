# 微信投稿素材的制作规格

下表按 2026-11-12 核对的微信表情开放平台指南整理。再次制作投稿包时核对平台现行规格。数字针对对应栏位，同为横幅的图片也可能有不同的体积上限。[微信表情制作规范](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/makingSpecifications)

| 后台栏位 | 格式、像素、上限 | 美术处理 |
| --- | --- | --- |
| 聊天动图 | GIF，240 × 240，500 KB / 枚 | 本套使用透明底、循环播放。一套专辑可提交 8～24 枚，同套统一动静类型。《奶家族动起来》是 16 枚。 |
| 专辑详情页横幅 | JPG 或 PNG，750 × 400，500 KB | 横向场景，有背景，尽量无字。人物保持比例，排得下完整动作。 |
| 专辑封面 | 透明 PNG，240 × 240，500 KB | 用一眼认得出的代表动作，半身或全身，避免白边、边框和挤成一团。本套定稿是奶蛙低头抱着笑眯眯的奶蛋。 |
| 聊天面板图标 | 透明 PNG，50 × 50，100 KB | 简洁、居中的头部或面部特征。按 50 像素真大小查看。 |
| 赞赏引导图 | GIF 或 PNG，750 × 560，500 KB | 需要赞赏配图时制作，有背景，角色和专辑同款。 |
| 赞赏致谢图 | GIF 或 PNG，750 × 750，500 KB | 与引导图有不同的画面落点，本套用池塘合照。 |
| 艺术家头像 | JPG 或 PNG，640 × 640，500 KB | 独立方形构图，缩小后也认得出主体。 |
| 艺术家主页横幅 | JPG 或 PNG，750 × 400，**80 KB** | 横幅两侧留余地。在目标画布重新排版能保住脸形和脚底。 |

聊天动图可以按「编号-角色-动作」命名，每枚配一个贴合场景或情绪的普通话含义词，最多 4 个汉字，尽量避免标点和重词。如果预览顺序变过，按画面核对每个词。本套有 12 枚无字、4 枚带短字，往后按内容决定是否配字。

制作投稿包时，聊天动图与专辑配图分文件夹，艺术家资料图另存。需要文案时，名称限 8 个汉字、简介限 80 个汉字、版权栏限 10 个汉字，赞赏引导语为 5～15 个汉字。按实际来源记录原图和新绘动作。

## 检查导出的动图

检查脚本需要 Python 3 和 Pillow。从技能目录运行，目标可以是单枚 GIF 或聊天动图目录。加 `--album` 会核对数量，列出混入的其他图片，并指出画面和停顿完全相同的两枚。用 `--hold-ms` 检查指定动作的终姿停留。加 `--preview` 可导出浅、深底的起始、中间和末帧对照，专辑对照图存到聊天动图目录外。

```sh
python scripts/check_gif.py "你的聊天动图目录" --album
python scripts/check_gif.py "08-奶鼠-分你一口.gif" --hold-ms 650 --preview "奶鼠检查.png"
python scripts/check_gif.py "14-奶猫-给你踩踩.gif"
```

工具读取交付的 GIF，核对画布、体积、可见变化、外缘透明、空帧、帧时长、循环标记和终姿停留。预览里的数字是帧序号，中间帧按序号选取。眼睛有无杂色、几枚动作是否雷同，以及首尾衔接是否自然，都要结合原图和实际播放来判断。
